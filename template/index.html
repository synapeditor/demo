License · Loaded from license.config.js, already filled in if you set up via synapeditor.com. License setup guide
  1. Get a license — an Evaluation / Issue license for local testing, or a Production license for your own domain.
    Visit synapeditor.com or email support@synapeditor.co.kr.
  2. Fill in license.config.js — your company name, your key, and the editor.license.load.api block, all copied from the dashboard.
    An Evaluation / Issue license is checked online on every load, so without that block the editor shows "Invalid License."
  3. Open it on localhost — an Evaluation / Issue license works only on localhost; file://, 127.0.0.1 or another IP shows "Invalid License."
    A Production license works on the domain it is registered to.
// license.config.js — at the project root
var synapEditorLicense = {
    'editor.license': {
        company: 'Your Company',
        key: ['YOUR-LICENSE-KEY']
    },
    // Required for an Evaluation / Issue license — paste both from the dashboard
    'editor.license.load.api': { url: 'https://www.synapeditor.com/api/v1/load-check', apiKey: 'se_test_...' }
};
